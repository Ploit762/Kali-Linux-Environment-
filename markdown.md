# Basic Kali Linux Commands

Here is a list of some basic commands I use frequently in Kali that is very useful when needing to maneuver around the terminal. Take a look..
- (cd..) change directory
- (pwd) display the path you are currently in
- (ls) list out what is in the directory
- (sudo gzip -d `file name`) unzips file
- (Cat `file name`) outputs data from file
- (nano `file name`) use to create or open existing file
- (mv `file name` `destination`) move a file from one place to another
- (mv `file name` `new file name`) rename a file that was already created
- (cp `file name` `new filename`) copy file that is already made
- (rm `file name`) remove file
- (mkdir `name of directory`) create directory/folder
- (rm -R `name of directory`) remove directory/folder 
- (sudo) super user privileges
- (Sudo nmap `ip address`) IP scan
- (sudo nmap `domain`) scan a domain
- (sudo nmap `ip adress`-254) scan a range of IPs
- (Sudo nmap `ip address` -sV) find the version of the service running on the port
- (Sudo nmap `ip address` -O) detects the OS version of the port
- (Sudo nmap `ip address` -p-) port scan all ports on network
- (Sudo nmap -p `ip address`) scan a specific port
